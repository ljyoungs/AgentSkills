# A｜完整口播与对应画面

**题目：冰箱门开着，房间会变凉吗？**

口播约三分钟，具体时长随语速和停顿调整。以下生活场景与画面均为说明原理的设计，没有进行真实实验，也没有测温数据。

## 完整口播

**主讲：**

天太热，你打开冰箱，站在门口，终于舒服了一点。这个时候，很容易冒出一个主意：我干脆把门一直开着，再搬把椅子坐过来。等冷气慢慢散开，整个房间，是不是都能凉下来？

先把这个房间交代清楚：我们暂时忽略它跟外界的热量交换，冰箱一直通着电，门也长期打开。接下来看的，是整个房间最后会怎样。

你站在冰箱门口，确实可能感觉到凉。这个感觉很有说服力：冷气已经出来了，只要继续吹，房间总会越来越凉吧？可这里有个地方，我们一直没有看——冰箱把里面的热，搬到哪儿去了？

**搭档：**

搬到冰箱外面……那不还是这个房间里吗？

**主讲：**

对。门关着的时候，这件事很好理解。冰箱里面是一个小空间，它把里面的热搬出来，排到外面，所以里面能保持低温。你看见了一个变冷的小空间，承担这些热量的，是外面的房间。

现在，我们把门打开。原先隔开的两个地方连在一起了。门口有冷气出来，冰箱也继续把热往外排。你只站在门口，会很容易注意到舒服的那一边；可要判断整个房间，就得把另一边也算进去。

咱们把热量当成几箱东西。你从房间这边搬走几箱，又把它们放到房间那边。刚才那个角落腾空了，但整个房间里的箱子，并没有少。冰箱也是一样：它把热从一处移走，再排到同一个房间里，房间没有因此把这份热送出去。

事情到这里，还没有算完。搬箱子得出力，冰箱搬热，也要耗电。压缩机做的功，最后也会变成热。这样一算，冰箱排到房间里的热量，等于它移走的热量，再加上用电带来的那一份。

**搭档：**

所以，门口这点凉我能感觉到，可房间还要接下它排出来的热？

**主讲：**

没错。这就是为什么，“我站在这里感觉凉”，还不能推出“整个房间正在降温”。一个说的是你身边的局部，一个要算房间里所有的热。冷的一边、热的一边，加上耗电，得放到同一本账里。

所以，在刚才说的条件下，冰箱门长期开着，整个房间不会因此变凉。它还会得到冰箱耗电带来的额外热量。

下次再站到冰箱门口，你可以留意一下这个很容易被漏掉的问题：热从这里搬走之后，最终去了哪里？如果它还留在房间里，门口这阵凉风，就没有替整个房间把热送走。

# B｜文字审稿与实质修订

原稿的核心原理正确，讨论条件也齐全。主要问题是答案讲完之后，后文几乎没有新增的理解过程；搭档没有带来观众的新问题，结尾又把开头重复了一次。

| 可定位位置 | 问题 | 修订方向 |
| --- | --- | --- |
| 开头“答案是不能，因为……” | 开头直接交出结论可以成立，但这里连理由一起说完，后面没有留下值得继续追问的问题。 | 紧接着提出真实疑惑：“可站在门口明明觉得凉，这个感觉又怎么解释？”让后文承担解释任务。 |
| “先看第一部分……冰箱是保持低温的电器” | 定义没有帮助观众解决当前疑惑，章节播报也把一次推理拆成了目录。 | 从“里面能冷下来”直接追问“移走的热去了哪里”，让下一句由上一句自然引出。 |
| “第二部分……”至“第三部分……” | 两个事实挨着出现，但没有把“移走多少、排回多少、额外增加多少”连成一笔账。 | 先说明热仍在同一房间，再补上电功，观众才容易理解为什么局部冷气不能代表整体降温。 |
| 搭档“明白了，原来是这样，真有意思！” | 只有赞同，没有改变内容走向，删掉后也不影响理解。 | 让搭档提出“门口明明有凉气”的疑问，主讲据此解释局部与整体。 |
| “最后总结……”及随后一长句条件 | 结论重复，关键条件却到最后才出现，观众此前可能一直按自己家实际情况理解。 | 提前交代条件；结尾用“热最终有没有离开房间”收束，让观众带走一个能复述的判断方法。 |

**一段可直接替换原稿中后半段的修订：**

**主讲：**咱们先约定，忽略房间跟外界的热量交换，冰箱一直通电，门长期开着。现在只看整个房间，会不会变凉。

**搭档：**可我站在门口，明明就能感觉到凉啊。

**主讲：**这点凉，确实解释得通。冰箱把一处的热移走，那一处就能冷下来。接着要问的是：移走的热去哪儿了？它被排到冰箱外面，还是这个房间里。

**搭档：**相当于从房间这头，搬到了那头？

**主讲：**对，所以整个房间没有少掉这份热。再算一笔：搬热要耗电，压缩机做的功，最后也变成热。排回房间的热量，就等于移走的热量，加上电功带来的那一份。

所以，门口的局部凉感可以存在，整个房间却不会因此降温，还会得到耗电带来的额外热量。下次判断这类问题，别只看哪里变冷了，再追问一步：移走的热，最终有没有离开我们讨论的这个空间？

# C｜三个不同的开头钩子

1. **生活场景：**天太热，你打开冰箱，搬把椅子坐在门口。这里确实有点凉。那就让门一直开着，这点凉，能不能慢慢变成一整个房间的凉？

2. **反常疑问：**冰箱能把里面变冷。那把门打开，让里面跟房间连起来，为什么整个房间却不会跟着凉下来？这个看起来顺理成章的主意，究竟漏算了哪一笔？

3. **搭档发问：**搭档：“冷气都出来了，房间总该凉一点吧？”主讲：“我们现在只盯着门口。把目光挪到冰箱排热的那一边，再看看整个房间里发生了什么。”

# D｜资料不足时的结构方向与关键缺口

可以先沿着这个问题讨论：**“植物的反应，可能受到过去经历的影响吗？”** 这个问法能承接标题里的“记忆”，也给证据核查留下空间。仅凭标题，目前还不能判断作者所说的“记忆”具体指什么，更不能确定存在怎样的科学机制。

暂定结构可以这样推进：

1. **先说明要观察的现象。** 把“记忆”暂时写成一个待检验的问题：一株植物经历过某种刺激后，等刺激撤除，再遇到相同条件时，反应是否与没有经历过的植物不同？这一段只提出判据，不宣称已经观察到结果。
2. **再问怎样区分过去的影响与眼前的差异。** 如果以后拿到实验，重点看刺激是否真正结束、比较条件是否一致，以及差异是否可能来自尚未消退的状态。相关排除没有完成时，不能直接把反应差异叫作“记住了”。
3. **有可靠现象后，再讨论机制。** 先确认研究实际发现了什么、效果能持续多久、是否能够重复；随后才看研究者是否提出并检验了机制。现象、解释与推测要分别说清楚。
4. **结尾回到这个词能用多远。** 即使有证据支持过去经历影响后续反应，也仍需交代“记忆”在该研究中的定义，避免让观众自然理解成人类式的回想或主观体验。

目前最关键的缺口是：标题的出处和原文；涉及哪一种植物、哪一种刺激；“记忆”的操作性定义；实验流程、对照与实际结果；效果持续时间、重复情况及统计依据；作者对机制和局限究竟说了什么。

拿到材料后，应先判断它足以支持上述哪几步，再决定故事如何展开。现阶段适合保留结构讨论，具体发现、实验情节和机制结论都还没有材料可写。

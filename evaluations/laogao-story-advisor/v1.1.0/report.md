# v1.1.0 新输入文字试用记录

日期：2026-10-18。本轮验证“换题后是否能完成实际请求”，没有测量视频留存、爆款概率或与真人创作者的相似度。

## 怎样做的

- 两个隔离子会话分别完成同一份[四项请求](requests.md)。一组加载候选Skill正文及相关参考，另一组不加载技能正文，均只用给定事实，不联网、不读旧稿、不执行媒体。
- 每组是**一次生成、同批四题**，不是每题多次独立重复。没有提供标准答案、怀疑的问题或预期赢家。
- 第三个隔离子会话只收到请求和匿名X／Y答案，不获知条件映射，作[首次对照复核](anonymous-review-first.md)。答案的格式仍可能提供线索，不声称严格双盲。
- 映射揭示：**X＝加载Skill，Y＝未加载正文**。基线仍处在客户端通用指令及技能元数据可见的环境中，不是无任何系统指令的基础模型。
- 未固定模型版本、采样参数或跨客户端环境；不把一次同环境文字比较当成因果实验。

保留[加载Skill的首次答案](candidate-first-output.md)和[未加载正文的首次答案](baseline-first-output.md)。公开副本只移除了末尾含本机路径的读取资源附录，答案正文没有润色；原始记录另行保留，未用重跑的更好答案替换首次结果。

## 实际结果

| 请求 | 首次结果 | 对照发现及限制 |
| --- | --- | --- |
| A 冰箱开门：约3分钟完整稿＋画面 | 两组都交出全部台词及对应画面，前置给定条件，无伪造实验 | X用“最多白忙活？”带出电功，视觉解释逐步对应推理；Y的口语和搬箱子类比更轻便。X小幅占优是文本复核判断，不是观众测试 |
| B 审事实正确但平淡的稿 | 两组都有定位问题和实质修订 | X的搭档转折和替换范围更完整；Y明确说明先给结论也可成立，但把实际适合替换全文的修订称作“替换中后半段” |
| C 只给三个钩子 | 两组均恰好三条，未扩成全稿或分镜 | X切入概念更多样，Y表达形式更多样，复核判平局 |
| D 只有植物记忆标题 | 两组均给可讨论方向与资料缺口，没有编出已证实机制 | X更重来源适配，Y更重具体对照问题，复核判平局 |

两组都能完成任务，因此本轮不能证明“不用Skill就做不好”。当前证据支持Skill可用于这些请求，在部分推理交接与画面对应上有编辑优势；不能证明稳定增益或整体表达优于基线。

## 根据实际问题改了什么

首次X答案B中“观众很快失去继续听的理由”把编辑推断说得过于确定。审核表已窄改为：没有受众数据时，用文本依据描述**可能**的影响，并明确实际替换范围。首次答案与匿名复核均保留原样，读者可核查这一问题。

窄改后，另一个没有旧输出上下文的隔离会话只收到原B请求和最新Skill，完成[一次单项复测](candidate-B-after-update.md)。主会话核对看到“可能削弱继续听的理由”等条件性表述，以及明确的“替换原稿全文”。这支持本次具体问题已得到回应；该单项没有再次做匿名对照，也不替换上面的首次结果。

未因Y口语较轻便就新增“永远缩短”一类规则，也没有把本次测试题写入核心指令的固定套路。版本的目标仍是可选择的叙事方法、完整交付与可核查的审核。

## 尚未验证

没有实际配音、完整视频、真人听看、受众留存、平台发布、跨模型／客户端复现或大样本统计。原片依据另受“仅两期全片ASR＋定时抽帧”的范围限制；本测试不补足真人风格相似度的证据。

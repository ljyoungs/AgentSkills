# 照片一键节奏视频

用户只上传图片并描述想法，助手负责找附件、读取固定配乐、制作和交付 MP4。不要让用户填写音乐路径、BPM、鼓点或首次配置表。首次使用条件、安装和兼容范围见 [README](README.md)。

## 选择制作方式

- **同款／甜酷摇滚**：读 [甜酷模板](references/sweet-cool-rock.md)，执行“原图 → 少量完整造型图 → 一段真实人物动态 → 视频末帧定格跳动”。默认约 12–18 秒，9:16、1080×1920、30fps；时长按素材调整。
- **只做原照片卡点**：直接调用 `photo_beat.py make --mode photos`。不产生人物动作，也不把推拉缩放称作图生视频。
- 用户先讨论、只要提示词或问歌名时，回答对应问题，不启动制作。人物、产品、宠物按实际素材设计；不要把女童造型硬套给所有输入。

## 执行与依赖

1. 查看图片，确认主体、完整道具及顺序。保留原照片；同款开头默认最多前三张，省略项写入计划。用户明确指定的素材数量和顺序优先。
2. 检查当前工具：读图、参考图生图、图生视频、文件读写和剪辑导出。完整同款需要这些能力；缺项如实说明，保留已完成素材，不把提示词当成成片，也不自行降级成纯照片版。
3. 运行音乐缓存脚本。固定音源、SHA256和鼓点在 [模板配置](references/template.json)。首次从指定来源下载，以后读缓存；下载失败或哈希不符即停止配乐，不猜歌、不换歌、不让用户补音乐文件。
4. 用当前环境真实可用的图片生成工具生成造型图。这个包不内置商业生图账号或生图模型。每张参考同一原人物，保持年龄、外貌、物体结构和整体气质；完整主体与道具优先。看图后再推进。
5. 对选中的一张造型图生成真正的主体动作。优先用当前已接入工具；需要复用公开 LTX 路线时读 [图生视频操作](references/image-to-video.md)，使用随包的 `image_to_video.py`。公共演示有配额和排队，未保证永久免费。只提交一次；未知提交结果用同事件恢复，不能重复提交。自动操作受阻或用户要自己生成时，用随包的 `handoff` 命令交付图片、提示词与参数，保留已完成素材；待返回视频后检查并继续原剪辑。
6. 选择手、脸、道具和边缘稳定的动态区间，调用渲染脚本。全段不合格就说明局限并返修，不能仅凭帧差宣称动作自然。默认不混入生成视频自己的声音。
7. 检查完整解码、音轨、声画时长、逐镜及切点抽帧，查看人物、道具与最后定格。技术通过、模型看帧和用户审美批准分别记录。交付可播放 MP4、制作回执及限制；不自动上传或发布。

脚本路径相对本技能目录，实际执行时解析为绝对路径；参数由助手填写。依赖 Python 3.10+、Pillow、numpy、requests，以及 PATH 中的 FFmpeg／FFprobe。

```bash
python -X utf8 scripts/music_cache.py
python -X utf8 scripts/photo_beat.py plan --input photo1.jpg --input photo2.jpg
python -X utf8 scripts/photo_beat.py make --input photo1.jpg --input photo2.jpg --out new-run
python -X utf8 scripts/photo_beat.py make --mode sweet-cool --input photo1.jpg --input photo2.jpg --input photo3.jpg --styled car.png --styled amp.png --styled guitar.png --motion guitar-motion.mp4 --motion-start 0 --motion-duration 3 --speed 0.8 --out new-sweet-run
```

`plan` 完全离线，不下载、不生成。`make` 自动获取固定音乐并渲染；默认输出当前工作目录 `outputs/photo-beat-video/` 的新时间戳子目录，可由用户指定其它位置。禁止覆盖已有制作目录；大媒体存到用户当前指定磁盘，不能硬编码作者机器路径。

同款默认少量完整造型，但不限制为两三张。`--styled` 按给定顺序排列，可穿插多人单照与合照；`--styled-seconds` 调整每张停留时间，默认1.3秒。用户明确要保留更多开头原图时设置 `--max-opening`，并检查计划中的省略项。多人身份及互动设计见 [甜酷模板](references/sweet-cool-rock.md)。

## 音乐约束

固定的是已核实的抖音作品原声，原曲歌名尚未鉴定。来源下载得到 MP3，校验后转 AAC 便于播放器兼容；不改变速度、音调、增益，不加淡入淡出或其它声音。剪辑时复制缓存 AAC 的开头编码包，可截短。不能把跨编码封装写成与作者历史本地 AAC 文件字节完全一致。

音轨只缓存在使用者设备，不随仓库分发；代码的 MIT 许可不授权第三方音乐。来源引用和缓存方式见 [NOTICE](NOTICE.md)。不绕过登录、付费或访问限制。

## 状态与复用

生成过程中每约 60 秒报告最后确认的阶段；已提交不等于 GPU 开始运行，空错误不猜原因。依实际授权使用在线额度，不自动购买或充值。免费额度耗尽时保留中间成果并说明，不伪装后台仍在运行。

随包图生视频客户端为匿名请求，不复用网页登录额度；接口可达不等于账号有额度。只需基础原图卡点时无需在线生成；用户要求完整同款但额度不足时，不能未经说明改交纯照片版。用户明确结束制作后停止生成和重试，只保留现有成果。

安装后的对话示例见 [调用示例](references/portable-prompt.md)。实际制作取决于当前环境的模型、脚本执行权和额度。验证范围见 [验证记录](references/validation.md)。

# 给能读仓库的智能体的一句话

将图片附在同一条消息中：

```text
请读取并使用 https://github.com/ljyoungs/AgentSkills/tree/main/skills/content-creation/photo-beat-video 的完整技能，用我上传的照片做甜酷摇滚卡点视频，使用技能固定配乐，保留完整人物与道具，结尾定格跟鼓点跳动，交付MP4。
```

这句话包含加载技能和发起制作两个意图。工具若支持安装，可以先安装；已有同名技能则按客户端规则使用或更新。只提供图片是正常使用方式，不能再让用户准备音乐、BPM或时码。

对于不能安装或执行脚本的普通聊天界面，可表达同样需求，但要如实告知能力边界：

```text
根据我上传的图片制作约12–18秒、9:16的温柔可爱又很飒的节奏视频。
开头原图随鼓点切换和轻闪；中间2–3张保持同一人物外貌、年龄的甜酷摇滚完整造型图，每张短暂停留并轻闪；将其中一张持电吉他图生成低头轻拨琴弦、抬头微笑的自然动态；结尾用实际视频末帧定格，跟随鼓点轻微跳动。保持完整人物、鞋子与乐器，暖色电影光影，真实皮肤和衣物质感。
音乐自行从固定来源 https://www.douyin.com/note/7700553825958758257 获取实际原声，只截短，不改速度、音调或音量。不能取得时说明限制，不换歌、不交付静音假成片；不要让我另外上传音乐。
先检查真实可用的出图、图生视频与剪辑导出能力，有能力直接执行；缺少则说明并保留已完成素材。优先免费额度，不自行付费。
```

复制文字不等于客户端拥有本地执行环境或生成额度，不能承诺任意聊天窗口一键完成。

多人版本在上述需求中补充：“中间按我指定的顺序穿插每个人的完整造型图和合照，保持各自外貌与年龄；结尾从合照生成一个小幅互动镜头。保留已认可的形象，不擅自美化或换脸。生成服务受阻时交付可打开的参考图、完整提示词与建议参数，说明尚未生成，收到我的MP4后继续剪辑。”

只需让一张图动起来，可独立发：

```text
请安装并使用 https://github.com/ljyoungs/AgentSkills/tree/main/skills/content-creation/image-to-video ，让这张图按我描述的动作自然动起来，保留主体、道具与完整构图，先检查可用服务和额度，交付MP4。
```

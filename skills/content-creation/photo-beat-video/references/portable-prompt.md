# 安装后调用示例

按 [一句话安装](../README.md#一句话安装) 让智能体确认技能可调用。随后上传照片，并按需要补充主体、道具和镜头顺序。

```text
使用 photo-beat-video，把我上传的照片做成 12–18 秒的竖版甜酷摇滚卡点视频，使用技能固定配乐。保留人物外貌、鞋子和电吉他，安排低头轻拨琴弦、抬头微笑的动态镜头，最后用该镜头的末帧随鼓点定格。交付 MP4。
```

多人版本可补充“中间按我指定的顺序穿插每个人的完整造型图和合照，保持各自外貌与年龄。结尾用合照生成一段轻微互动，保留已经确认的形象。”

智能体负责准备音乐和时码，并检查当前环境的出图、图生视频和剪辑能力。在线生成受阻时，可按 [图生视频操作](image-to-video.md) 保留素材并交接参考图、动作提示词和参数。各客户端的运行条件见 [技能说明](../README.md)。

# 验证记录与边界

本包将实际照片卡点与图片生成视频的制作方法整理为可移植技能。历史反馈支持：保留原图、少量完整造型、短动态、末帧跟鼓点跳动；反对重复特写、突然灰化、过长停留和明显道具变形。家庭素材、历史成片和原始聊天不随包分发。

## 可执行检查

在仓库根目录运行：

```bash
python scripts/validate_catalog.py
python -m unittest discover -s tests -v
```

测试用自行生成的几何图、测试动态图和正弦音轨；不上传家庭照片，不调用远端生成。覆盖：

- 固定源哈希校验、第二次离线缓存、源文件变化和缓存损坏时停止。
- 照片顺序、帧时间线、原素材保留与已有版本不覆盖。
- 完整模板必须有真实视频输入，拒绝超出原片的区间。
- 真实 FFmpeg 渲染、完整解码、声画时长、配乐缓存编码包复制。
- 从实际所选视频末帧定格、编码后闪动可见且保留彩色。
- 图生视频适配器的未知提交不重发、空错误不猜原因、下载恢复不重新生成和声音选择。

2026-11-05 首次公开整理验证：22项仓库及行为测试通过，两个新技能格式检查通过，固定公开音源下载后的SHA256与配置一致，生成14.1秒原生1080×1920、30fps合成测试片并通过完整解码、声画时长和AAC缓存编码包前缀校验。测试片画面是自行绘制的几何人物与测试动态图，不是新生成的人像或演奏视频；不附带或公开测试音轨。

同日只读检查了LTX演示参数结构，接口可达且参数顺序一致；没有再次提交远端生成，不据此断言有可用GPU配额。代码检查和合成检查不等于跨平台、人物自然度或用户审美验证。

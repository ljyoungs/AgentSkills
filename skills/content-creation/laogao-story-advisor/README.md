# 老高叙事方法 Skill

**社区非官方版 · v1.1.0 · MIT · 中文优先 · 无必需外部服务**

输入选题和资料，得到有观看动机、有逻辑、可审核的原创故事方案。适合科普、知识解说和案例视频，提供选题、结构、完整口播／分镜以及内容与发布包装审核四个入口。

“AI蒸馏”在这里指将有限公开样本中可观察的讲述方法，以及实际改稿反馈整理成可复用指令。它不是模型权重训练、真人替身或官方出品，不包含真人声音。

## 一句话安装

把下面这句话发给能访问 GitHub 并安装技能的 Codex 或 WorkBuddy。

```text
请从 https://github.com/ljyoungs/AgentSkills/tree/main/skills/content-creation/laogao-story-advisor 安装 laogao-story-advisor 技能，并确认它已能在当前智能体中调用。
```

安装后，直接在对话里说你的任务。文字策划可离线使用，资料检索取决于当前客户端。

```text
使用 laogao-story-advisor。
选题：没有大脑的大肠杆菌，怎么找到食物？
受众：普通中文观众。
资料：我提供的两份来源摘录。
先给结构：用“找吃的”贯穿；不要在开头把全部机制揭晓。
```

## 可以怎么用

| 入口 | 示例要求 | 结果 |
| --- | --- | --- |
| 选题 | 根据资料找一个最值得追问的问题 | 题眼、观众收益、线索与缺口 |
| 结构 | 先给一条完整故事线 | 每段观众猜想、线索、理解变化与下一问 |
| 完整稿 | 把已确认结构写成自然口播和分镜 | 原创逐字稿、可见动作、来源身份与素材状态 |
| 审稿 | 检查我的稿、封面、标题和正文是否抓人 | 具体问题、返工内容和有范围的复核结论 |

输出范围由请求决定。用户只讨论题眼时不生成整套剧本；本包不自动生成配音、渲染视频、上传或公开发布。

## v1.1补了什么

- **规则有依据**：[原片参照表](references/episode-mapping.md)将两期官方节目扩展到全片ASR及定时抽帧，列出观察、编辑转化与不适用条件；并非完整人耳视听或全频道统计。
- **能落到句子**：[叙事手册](references/narrative-mechanics.md)提供不同材料的推进路线、信息先后、因果桥段、术语引入、搭档接话及结尾的具体改写。
- **完整稿能检查**：大肠杆菌示例交付所有应读台词和全稿分镜；范围小的请求仍只做相应部分。
- **审稿不止查错**：单独检查前后重复、追问不成立、搭档无作用、类比增加负担及结尾无新增认识。
- **换新题实用一次**：[验证记录](references/validation.md)保留四项新请求的首次对照输出和匿名复核；基线也能完成任务，不夸大Skill增益。

## 能证明什么

技能格式、链接和独立文件包的校验，只证明包可以被读取，不能证明故事好看。方法来源与观察限制见[方法证据](references/evidence.md)。内容与封面审核是编辑判断，不保证传播结果；实际成片的声音和动态节奏需以真实视听检查为准。

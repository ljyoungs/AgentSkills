# 审稿示范：把“神奇”变成可兑现的疑问

2026-10-17主会话按审核表执行的文字用例，没有查看或假定存在最终封面实图／成片。

## 输入

```text
帮我审核这个草稿和封面方案：
标题：震惊！没有大脑的大肠杆菌，竟然有意识！
封面文字：它每次都能准确找到饭！
开头：它靠延长直游和化学记忆找到食物。下面先认识CheA、CheY、CheR、CheB。
中段：展示一次普通游动显微视频，说这就证明它记得路线。

```

给定事实：直游／翻滚的概率与环境变化有关；许多次行为可产生趋向；短期化学状态不等于意识；普通游动录像不直接证明地点记忆。

## 审核与实际改法

| 位置 | 问题及观众影响 | 修订 |
| --- | --- | --- |
| 标题 | 从化学状态跳到意识，关键事实超出材料 | “没有大脑的大肠杆菌，怎么找到食物？” |
| 封面方案 | “每次准确”把统计倾向说成必然，还提前承诺终点 | “没有大脑，也能找吃的？”；实际图需另看手机缩图和裁切 |
| 开头 | 第一行说尽机制，随后用蛋白清单代替故事 | 先看直游后翻滚，问“如果下一次方向不是提前选好的，趋向从哪里来？” |
| 中段 | 普通游动录像被当成记忆证据 | 把画面标为普通游动；化学状态另用有来源的机制说明，不能冒充直接拍到了记忆 |
| 结尾 | 只重复结论，没有重新解释开头 | 回看同一次翻滚，解释改变的是下一次再试的时机；保留食物释放可感吸引物的条件 |

## 修订后的短段落

先看这只大肠杆菌：游一阵，翻滚，再朝另一个方向走。如果它没有先选定目的地，这种走法为什么还可能逐渐靠近有利环境？我们要追的不是它脑子里有没有地图，而是沿途发生的变化，怎样影响下一次翻滚。普通游动镜头只能让我们看见运动；要解释其中的偏向，还得接上具体的化学线索和机制证据。

# 原片参照与规则映射

整理：2026-10-18。两期均核对官方频道身份；本轮读取全片音频的本地ASR转写，并查看每30秒一帧及片尾帧的联系表。《第二名》60帧，《三体》78帧。**这不是全片人耳听审、连续动态观看或可靠的说话人分离。** ASR存在错字；下面是约略定位的功能观察，不作为逐字引文或准确剪辑点。节目中的科学、历史和小说解读须另查领域来源。

## 两种不同的推进方式

### P1《第二名》｜29:07

[官方原片](https://www.youtube.com/watch?v=SHWjQrGb3MQ)，频道老高與小茉，发布日期2026-07-22。

| 约略区间 | 可观察的组织选择 | 写作时可迁移什么 |
| --- | --- | --- |
| 00:00–01:20 | 排名疑问与预期落差先建立兴趣，再点出主题及警告背景 | 给观众一个具体缺口，再交代它为何值得追；排名本身不是本包核实事实 |
| 01:20–05:55 | 从镜像、左右手等熟悉对象，进入分子层面的差异 | 用一个可理解的关系承接陌生概念；进入名词前有对象 |
| 05:55–10:00 | 研究进展之后补充功能与适用对象；追问触及先前解释的缺口 | 每个突破都说明“做到了哪一步”，不要把零件成功说成完整生命 |
| 10:00–14:45 | 看似有利的“互不兼容”，被继续追问其后果 | 转折来自同一性质在新条件下的结果，不另空降一则奇闻 |
| 14:45–25:35 | 追问研究动机，转向用途、起源疑问、进展 | 在观众产生“为何还要做”时再讲动机；不照搬所有支线 |
| 25:35–片尾 | 开放式聊天、类比和医学话题延伸 | 原片并非严格闭环收束；短片是否保留闲谈应由主线与时长决定 |

抽帧中可见大量资料图、机制示意与字幕画面。部分采样位置为暗场；不能仅凭这些帧确定整段剪辑速度或主持人表演。

### P2《【神作】四十分鐘講完三體》｜38:21

[官方原片](https://www.youtube.com/watch?v=2vowHo2y-hI)，同一官方频道，发布日期2021-06-02。

| 约略区间 | 可观察的组织选择 | 写作时可迁移什么 |
| --- | --- | --- |
| 00:00–00:55 | 直接报作品、提供入口背景，穿插短接话及篇幅玩笑 | 允许叙述型开场，不必每题都制造谜案 |
| 00:55–06:20 | 先交代生存处境，再讲行动及其后果 | 观众需要先知道角色为何行动，才能理解后续选择 |
| 06:20–12:45 | 一个限制产生新的对策；解释新设定时伴随质疑 | 新术语应解决眼前问题；搭档可以追问可行性 |
| 12:45–22:40 | 并列尝试、结果与先前线索回收交替 | 埋下线索后让事件兑现；并列内容不能只列名称 |
| 22:40–26:40 | 先前事件后再集中解释规则，并进入生活类比和闲谈 | 规则能在观众已有具体经验后总结；类比不能升级成现实证据 |
| 26:40–片尾 | 新选择继续改变局面，逐步扩大尺度，最后回到日常聊天 | 复杂长故事可沿行动后果推进，不强制压成一次反转 |

抽帧中多次回到沙发双人主讲，资料画面穿插；这只支持整体画面类型的判断，不能据此计算对话比例、精确笑点或剪辑频率。本例是小说讲解，不能把其中世界设定当成现实科学结论。

## 从观察到指令，保留中间一步

| 规则 | 原片支持到哪里 | 本包的编辑转化／适用条件 | 反例与限制 |
| --- | --- | --- | --- |
| 开头给具体入口 | P1用缺口，P2直接进入作品 | 先决定题材适合异常、人物处境还是清楚的观看承诺 | “先做动态事件”不是两期共同不变量 |
| 解释伴随用途 | P1熟悉对象后引概念；P2在对策中解释设定 | 到观众需要这个概念时再命名 | 必要前提不能为悬念故意藏住 |
| 回答产生下一问 | P1兼容性推向后果；P2限制推向对策 | 逐段写清理解变化，详见[叙事手册](narrative-mechanics.md) | 不要求所有科普都倒转直觉 |
| 搭档有理解功能 | 两期转写含追问和插话，P2采样可见双人 | 可在条件、可行性和后果处设计原创接话 | ASR未可靠分人；不据此固定搭档比例 |
| 情境幽默与支线 | 两期都有类比、玩笑和闲谈 | 选与本题有关、能顺畅返回主线的部分 | 并非每段都要笑点；原片有支线也不等于短片该保留 |
| 结尾回看开头 | 两期并不共同表现为严格闭环 | 本包针对短科普提出回扣建议，方便兑现观看承诺 | **这是编辑建议，不冒称原片通用精髓** |

两期跨题材样本只能支持这些局部、条件性的观察。没有统计全频道、比较其他创作者或测量观众留存，不能证明方法独有、覆盖全部作品或必然提高播放量。更换参照节目时重新记录观察范围，不把此表当成已看过新原片。

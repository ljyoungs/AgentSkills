# BOSS 在线简历页面操作

## 确认浏览器与目标页面

1. 优先复用已附着的浏览器会话。用户指定 CDP 时，沿用已有 CDP 会话或常驻 worker。需要定位连接时，先检查本地现有 Chrome 进程、调试入口和标签页。必要时用已发现端点的 `/json/version` 和 `/json/list` 交叉确认。旧端口失效时重新核对实际入口。只有现有连接都无法使用且新连接需要授权时，才交由用户完成授权。核实后复用同一连接。
2. 确认是用户正在使用的浏览器实例、正确的 BOSS 标签页和目标账号。用界面上足以区分账号的信息核对即可。通过求职者侧可见导航进入在线简历，确认当前页面是对应简历的编辑界面。有多个可能账号或简历时，先确定目标再写入。
3. 根据页面当前可见的区块、表单标签、按钮和校验提示操作。浏览器连接仅用于操作可见界面。账号核验使用页面信息，禁止读取 Cookie、令牌或浏览器凭据，也禁止调用站点内部接口绕过表单。出现登录、验证码或安全验证时，请用户在现有页面上完成，再重新确认账号、页面和待处理项。站点限制或无法可靠连接时，交付字段稿。

## 核对表单字段

| 区块 | 页面核对 |
| --- | --- |
| 工作经历和项目经历 | 进入对应记录，确认同名条目的所属公司、时间和内容。已有记录用编辑入口，确属新条目才用新增入口。页面要求选择分类、职位或项目角色时，根据已确认经历匹配可用选项。有多项合理选择时暂缓该条，勿为通过校验随意选择。 |
| 起止时间 | 按工作或项目各自的起止月操作。打开日期选择器核对年份和月份。现行经历如有「至今」选项，使用该选项。已结束经历应设为明确截止月，检查「至今」状态是否关闭。回读时核对两个端点及该状态。 |
| 个人优势、教育与技能 | 确认可编辑区块和字段限制。遇到长度或格式校验，保留原意并检查实际内容是否被截断。技能名称有明确对应项时才选择。 |
| 项目链接和 PDF 附件 | 项目链接写到对应项目的可见链接字段，回读地址及所属条目。缺少合适字段时，将链接列为待手工处理。PDF 按明确授权在附件区单独操作，核对文件名和可见预览或文件信息。同名附件且无法区分时，暂缓替换。 |
| 隐私和可见性 | 留意编辑器和保存确认里的可见范围、展示选项和隐私开关。发现保存会连带改变未授权的设置时，停在提交前，记录涉及的选项。 |

## 逐条提交与回读

1. **建立基线。** 编辑前重读目标条目和待修改字段，与对照时记录的线上值比较。若值已变，按最新值重新对照。若用户同时修改了同一字段且意图不明，跳过该条。新增前再查一次列表，核对标题、所属方和时间，留意简称及旧标题。基线和回执只保留完成任务所需的信息。
2. **检查后保存。** 填写获授权的字段，检查目标身份、可见表单值、日期、必填项、链接以及提交范围。逐条提交，让结果可独立核对。页面结构发生变化时，重新读取界面，确认控件含义。无法判断当前控件作用或保存范围时，暂停该条。
3. **独立回读。** 退出编辑后重新打开对应条目，必要时刷新列表。核对实际存储的值，包括可能在列表里折叠的正文、起止时间、链接和附件。成功提示、表单关闭或新行暂时出现，都还需要回读。页面只能显示部分内容时，在回执注明已核验的字段和无法核验的字段。
4. **处理未知结果。** 超时、失去连接或页面报错后，先重新读取实际状态。目标值已存在时记为已核验，新增条目已出现时进入该条核对。只有在确认前次提交已经结束、实际值仍与原基线一致且可安全重提时，才考虑重试一次。发现部分保存、重复记录或仍无法确认结果时，停止重复提交，记录已核验的状态和剩余动作。

## 页面受阻时的交付

按可识别的区块和条目给出可直接粘贴的字段稿，附上准确的起止月、已确认的必填值及对应项目链接。列明要新增还是编辑，待确认字段单独标出。区分已保存并核验、原本一致、仅生成字段稿和结果未知。回执只提供用户定位问题所需的最少信息，避免附上完整个人资料、页面截图或登录信息。
